{% load i18n %} {% comment %} Mobile "Show more" toggle, shared by every knowledge card that trims itself on small screens. The knowledge panel stacks above the web results on mobile, so the cards ship cropped there (no hero image, no cast/crew, clamped summary); this button puts `.card-open` on the card root, which brings those parts back through the `card-open:` variant the templates carry next to their `sm:` ones. Progressive enhancement, in both directions: - `js:` — without scripting the button does nothing, so it isn't rendered at all; the card stays cropped and its footer link still reaches the full text on the source site.
